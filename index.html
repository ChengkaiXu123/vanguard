群聊Groups

@ 谁，就叫醒谁。
Bot 之间会接力。Mention a Bot,
it gets to work.

一句话 @ 两个 Bot，两个都醒来各干各的；Lens 修不了的，交给 Forge。每条消息最多连环唤醒 12 次，你点停止就停。没被叫到的，下次自动补看最近 40 条。Mention two Bots and both get to work; what Lens can’t fix goes to Forge. One message wakes at most 12 turns in a chain, and Stop ends it. A Bot that wasn’t called catches up on the last 40 messages next time.

装好之后After installing

想了解更多。Go deeper.

和直接开几个窗口，有什么区别？How is this different from just opening a few windows?
agent 还是各家原装的，Vanguard 多出来的是调度和送对人：@ 谁就叫醒谁，Bot 之间能接力，没被叫到的下次自动补看；终端里的 agent 能互相发消息；所有“需要你”的事合成一份；所有 agent 的历史一处搜。The agents are the same ones you already use. What Vanguard adds is routing: mention a Bot to wake it, Bots hand off to each other, and one that wasn't called catches up next time; terminal agents can message each other; everything that needs you is one list; and every agent's history is searchable in one place.
会不会把我的代码、密钥发出去？Does it send my code or keys anywhere?
Vanguard 自己不调模型。代码只交给你本来就在用的 agent，和你直接用它一样。Vanguard 没有遥测，不经云端中转，也不自动更新；配对另一台电脑时，内容端到端加密、只走直连。Vanguard calls no model itself. Your code only goes to the agents you already use, just as if you used them directly. There's no telemetry, no cloud relay and no auto‑update; pairing with another Mac is end‑to‑end encrypted and direct only.
token 算谁的？Whose tokens does it use?
算各家 agent 自己登录的账号，和你直接用它一样。有多个账号时，可以在 Vanguard 里切换。页面上的花费，是按本机记录和单价表估出来的。Each agent's own signed‑in account, exactly as when you use it directly. With several accounts you can switch inside Vanguard. Costs shown are estimated from local records and a price table.
为什么不自己做模型、自己写 agent？Why not build its own model or agent?
Claude Code、Codex 这些 agent，本身就是各家最强、更新最快的执行器。Vanguard 直接用各家官方接口驱动它们，它们一升级，Vanguard 就跟着变强；Vanguard 只做它们各自做不了的事：把它们组成一支队伍。Agents like Claude Code and Codex are already the strongest, fastest‑moving executors their makers have. Vanguard drives them through official interfaces, so it gets better whenever they do, and spends its effort on the one thing none of them does alone: making them a team.
只想要刘海上的 HUD，可以吗？Can I have just the notch HUD?
可以。装 SI Future HUD 就行，它会继续维护。以后想带一支小队了，再装 Vanguard，两个能同时装。Yes. Install SI Future HUD; it stays maintained. When you want a whole squad, add Vanguard; the two can live side by side.
